# bigdata-spark-kafka
Tarea 3 - Procesamiento de Datos con Apache Spark
Estudiante: Lina Paola Gutiérrez Jara

Descripción
Este proyecto tiene como objetivo analizar datos utilizando Apache Spark y comprender el procesamiento de datos en tiempo real mediante Apache Kafka y Spark Streaming.

Problema seleccionado
Predicción y análisis de precios de viviendas utilizando un conjunto de datos de Kaggle.

Dataset
House Prices - Advanced Regression Techniques.

Herramientas utilizadas
- Apache Spark 3.5.8
- Python
- Apache Kafka
- Spark Streaming
- Procesamiento Batch
Se realizó la carga de datos en formato CSV utilizando DataFrames de Spark y se ejecutaron operaciones de análisis exploratorio.

Resultados
- Lectura correcta del archivo CSV.
- Visualización de registros.
- Procesamiento de datos mediante Spark.
- Evidencias
Las capturas de ejecución se encuentran en la carpeta evidencias.
