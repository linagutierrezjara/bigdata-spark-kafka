# bigdata-spark-kafka
Tarea 3 - Procesamiento de Datos con Apache Spark
Estudiante: Lina Paola Gutiérrez Jara

# Descripción
Este proyecto tiene como objetivo analizar datos utilizando Apache Spark y comprender el procesamiento de datos en tiempo real mediante Apache Kafka y Spark Streaming.

# Problema seleccionado
Predicción y análisis de precios de viviendas utilizando un conjunto de datos de Kaggle.

# Dataset
House Prices - Advanced Regression Techniques.

# Herramientas utilizadas
- Apache Spark 3.5.8
- Python
- Apache Kafka
- Spark Streaming
- DataFrames
- Procesamiento Batch
Se realizó la carga de datos en formato CSV utilizando DataFrames de Apache Spark. Posteriormente, se ejecutaron operaciones de análisis exploratorio de datos, permitiendo visualizar los registros y verificar el procesamiento correcto de la información.

# Actividades realizadas
- Lectura de archivos CSV con Spark.
- Creación de DataFrames.
- Visualización de registros.
- Análisis exploratorio de datos.
- Procesamiento batch utilizando Apache Spark.
Preparación del entorno para procesamiento en tiempo real con Apache Kafka y Spark Streaming.

# Resultados obtenidos
- Configuración exitosa de Apache Spark.
- Ejecución correcta de scripts en Python.
- Lectura y procesamiento de datos mediante DataFrames.
- Visualización de los resultados en consola.
- Validación del entorno para proyectos Big Data.
# Archivos del proyecto
- analisis_batch.py: Script utilizado para el procesamiento batch de datos.
- README.md: Documentación general del proyecto.
- Evidencias de ejecución incluidas en el repositorio.

# Conclusión
Apache Spark permitió realizar el procesamiento de datos de manera eficiente mediante el uso de DataFrames, facilitando la lectura, análisis y visualización de la información. Además, el proyecto permitió fortalecer conocimientos en tecnologías Big Data y comprender la integración de herramientas como Spark y Kafka para el procesamiento de datos a gran escala.
